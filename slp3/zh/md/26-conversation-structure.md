# 26 会话及其结构

会话是一种精巧而复杂的联合活动，而会话是有结构的。所有会话都是如此，无论它们是人与人之间的会话，还是人与语言模型之间的会话。理解人类会话的结构是一项重要的社会科学与语言学任务。我们在研究人类会话时引入的这些概念，也可以成为分析人类与 LLM 会话的有用工具。

会话结构，以及如何用计算方式对它们进行标注。]

### 26.1.1 话轮

对话是话轮的序列（C1、A2、C3，依此类推），每个话轮都是一次单独的贡献

> `turn`（话轮）
>
> 释义：对话中由一位说话者连续说出的一段内容，是构成对话序列的基本单位。

由一位说话者对对话做出的一次贡献（就像在游戏中：轮到我，然后轮到你，接着又是我，依此类推）。图 26.1 中有 20 个话轮。一个话轮可以由一个句子组成（如 C1），尽管它可能短至单个词（C13），也可能长达多个句子（A10）。

话轮结构对口语对话有重要影响。人类必须
知道何时停止说话；客户进行了打断（在 A16 和 C17 中），因此扮演这一角色的系统必须知道要停止说话（并且知道用户可能正在作出更正）。

LLM 也会遇到同样的问题；系统还必须知道何时开始
说话。例如，在会话中大多数时候，说话者在另一位说话者说完之后几乎立刻开始自己的话轮，而没有很长的停顿，因为人们通常能够预测对方何时将要说完。

语音语言模型还必须检测用户是否已经说完，这样
它们才能处理该话语并作出回应。这项任务——称为断点检测——可能相当有挑战性，因为存在噪声，也因为人们常常在一个话轮中间停顿。

> `endpointing`（断点检测）
>
> 释义：在口语对话中判断说话者是否已经说完、从而使系统可以开始回应的任务。

### 26.1.2 言语行为

关于会话的一个关键洞见——最初由哲学家维特根斯坦（Wittgenstein，1953）提出，但由奥斯汀（Austin，1962）阐发得更为完整——是：对话中的每一句话语都是说话者正在执行的一种行动。这些行动通常被称为言语行为或对话行为：下面是包含 4 个

> `speech acts`（言语行为）
>
> 释义：说出某句话时所执行的一种行动，例如断言、请求或承诺。

主要类别的分类体系（巴赫（Bach）与哈尼什（Harnish），1979）：

断言类：使说话者承诺某事确实如此（回答、声称、
确认、否认、不同意、陈述）
指令类：说话者试图让受话者做某事的尝试（建议、询问、禁止、邀请、命令、请求）
承诺类：使说话者承诺未来采取某种行动（许诺、计划、
立誓、打赌、反对）
回应类：就某种社会行为表达说话者对于听者的态度（道歉、问候、致谢、接受回应）
用户要求一个人或一个对话系统去做某事（“把音乐调大”），就是在发出指令类言语行为（DIRECTIVE）。提出一个需要回答的问题，也是发出指令类的一种方式：从某种意义上说，当系统说出（A2）“您想在五月的哪一天出行？”时，就好像系统在（非常礼貌地）命令用户作答。相比之下，用户陈述一条约束（如 C1“我需要在五月出行”），就是在发出断言类言语行为（CONSTATIVE）。用户感谢系统，则是在发出回应类言语行为（ACKNOWLEDGMENT）。言语行为表达了说话者（或写作者）在说出其所言时意图中的一个重要组成部分。

### 26.1.3 共同基础建立

对话并不只是一系列彼此独立的言语行为，而是由说话者和听者共同完成的一种集体行为。与所有集体行为一样，重要的是

> `common ground`（共同基础）
>
> 释义：对话参与者共同认可并共享的信息与信念集合，是双方得以顺利交流的前提。

参与者确立双方都认可的内容，即所谓的共同基础
（斯泰尔内克，1978）。说话者通过为彼此的话语建立共同基础来做到这一点。建立共同基础意味着确认听者已经理解了说话者（克拉克，1996）。（人们在非语言行为上同样需要建立共同基础；电梯按钮被按下时会亮起，其目的正是确认电梯确实已被呼叫，实质上就是为你的按键动作建立共同基础（Norman，1988）。）当听者需要表明说话者未能成功完成某一行为时，建立共同基础同样重要。如果听者在理解上遇到困难，她必须把这些困难告知说话者，同样是为了最终实现相互理解。

> `grounding`（共同基础建立）
>
> 释义：对话双方相互确认对方已理解自己话语的过程，是达成相互理解所必需的一环。

这种闭合是如何实现的？克拉克和谢弗（1989）提出，每一个
共同的语言行为或贡献都包含两个阶段，称为呈现（presentation）与接受（acceptance）。在第一阶段，说话者向听者呈现一段话语，执行某种言语行为。在接受阶段，听者必须为该话语建立共同基础，向说话者表明是否达成了理解。

> `contribution`（贡献）
>
> 释义：由说话者与听者共同完成的一个联合语言行为单位，包含呈现与接受两个阶段。

听者 B 可以用哪些方法为说话者 A 的话语建立共同基础？克拉克
和谢弗（1989）讨论了一系列方法，按从最弱到最强的顺序排列：

持续注意（Continued attention）：B 表现出她仍在继续关注，因此仍然对
A 的呈现感到满意。

下一贡献（Next contribution）：B 开始进入下一个相关的贡献。

确认（Acknowledgment）：B 点头，或说出 uh-huh、yeah 之类的继续信号，或说出“太棒了”那样的评价。

演示（Demonstration）：B 演示出她对 A 所表达意思的全部或部分理解，例如
通过重新表述（改述）A 的话语，或通过协作式地补全 A 的话语。

展示（Display）：B 逐字复现 A 所呈现内容的全部或部分。

这类共同基础建立的例子出现在旅行社代理人对话中。我们
可以通过明确说出“OK”来建立共同基础，就像代理人在 A8 或 A10 中所做的那样。我们也可以通过重复对方所说的话来建立共同基础；在话语 A2 中，代理人重复了“五月”，向客户表明她的理解。或者注意，当客户回答一个问题时，代理人以“And”开头提出下一个问题。“And”意味着新问题是对旧问题的“补充”，再次向客户表明代理人已经成功理解了上一个问题的答案。

这一特定片段中没有确认的例子，但
另一个片段中有这样一个例子：

C: 他想从波士顿飞往巴尔的摩　A: Uh huh

| C: | 他想从波士顿飞往巴尔的摩 |
| --- | --- |
| A: | Uh huh |

这里的 uh-huh 一词是一个继续信号，也常被称为确认标记（acknowledgment token）或背信道。继续信号是一种（简短的）可选话语，它确认

> `continuer`（继续信号）
>
> 释义：听者在对话中发出的简短可选话语，用来表示自己正在跟进，且无需对方回应。

> `backchannel`（背信道）
>
> 释义：对话中听者发出的简短反馈，表明自己在倾听，本身并不构成一个话轮。

对方话语的内容，且不需要对方加以确认（英格维，1970；杰斐逊，1984；谢格洛夫，1982；Ward 和 Tsukahara，2000）。

### 26.1.4 子对话与对话结构

对话是有结构的。例如，考虑如下局部结构，它存在于

> `conversation analysis`（会话分析）
>
> 释义：研究真实对话中话轮组织、序列结构与修正机制的语言学与社会学分支。

会话分析领域所讨论的言语行为之间（萨克斯等，1974）。

问句（QUESTION）会为回答（ANSWER）建立起一种预期。提议（PROPOSAL）之后跟着接受（ACCEPTANCE，或拒绝 REJECTION）。称赞（COMPLIMENT，如“这件外套真好看！”）往往会引发谦虚回应（DOWNPLAYER，如“哦，这件旧衣服啊？”）。这些成对出现的现象称为邻接对，由第一部分与第二部分构成（谢格洛夫，1968），而这些预期可以帮助系统决定该采取什么行动。

> `adjacency pair`（邻接对）
>
> 释义：成对出现的话语，第一部分为第二部分设定预期，如问与答、提议与接受。

然而，对话行为之后并不总是紧接着其第二
部分。这两个部分之间可以隔着一段旁支序列（杰斐逊 1972）或子对话。例如，话语 C17 到 A20 构成一个纠正子对话

> `side sequence subdialogue`（旁支序列/子对话）
>
> 释义：插入在邻接对两部分之间、用于澄清或修正的一段从属对话，之后主序列再继续。

（利特曼 1985；利特曼和艾伦 1987；Chu-Carroll 和 Carberry 1998）：

C17: #Act...actually#，15 号是星期几？

A18：今天是周五。C19：呃嗯。我会考虑在那儿多待一天，待到周日。

A20：好……好。周日我有……

C17 中的提问打断了先前的对话，而在那段对话中，代理正在查找
5 月 15 日的返程航班。代理必须回答这个问题，同时还要意识到“我会考虑待到……周日”意味着客户很可能想更改计划，于是转回来查找返程航班，但日期改为 17 日。

另一种旁支序列是澄清性提问，它可以在 REQUEST 与 RESPONSE 之间构成一个子对话。这在对话系统中尤为常见：语音识别错误使系统不得不像下面这样请求澄清或要求重复：

用户：5 号有什么去 UNKNOWN WORD 的航班？

系统：让我看看，5 号去哪里？用户：去香港。系统：好，这里有几趟航班……

除了旁支序列，提问往往还有前置序列，如下例所示：用户在提出请求之前，先问了一个关于系统能力的问题（“你能预订火车票吗”）。

> `presequence`（前置序列）
>
> 释义：在真正提出请求之前先说出的那一问话轮，用来试探对方是否具备条件或意愿。

用户：你能预订火车票吗？系统：我能。用户：太好了，我想订一张下午 4 点去纽约的火车票。

### 26.1.5 主动权

有时一场对话完全由其中一方参与者掌控。例如，记者采访厨师时可能不断提问，而厨师作出回答。我们说在这种情况下，记者掌握着会话的主动权（Carbonell，1970；

> `initiative`（主动权）
>
> 释义：指对话由哪一方主导，谁在引导话题走向并决定下一步说什么。

Nickerson，1976）。然而在正常的人际对话中，更常见的情况是主动权在参与者之间来回转移：他们时而回答问题，时而提出问题，时而又把对话引向新的方向，有时则不然。你可能问我一个问题，而我回应时又请你澄清你说过的某句话，由此把对话引向各种方向。我们把这种互动称为混合主动权（Carbonell，1970）。

完全混合主动权虽然是人际对话的常态，却可能
让对话系统难以做到。最原始的对话系统往往采用系统主导型主动权：系统提出一个问题，用户在回答之前什么也做不了；或者像简单搜索引擎那样采用用户主导型主动权：用户给出查询，系统被动地作出回应。即便是基于大语言模型的现代对话系统——它们已相当接近使用完全混合主动权——也常常不能完全自然地切换主动权。把这一点做对是现代系统的一个重要目标。

### 26.1.6 推理与会话含义

推理在对话理解中同样重要。来看客户的回应 C3，此处重新列出：A2：那么，你想在 5 月的哪一天出行？C3：好呃，我得去那儿参加一个会议，会议从 12 号开到 15 号。

注意，客户实际上并没有回答代理的问题。客户
只是提到某个时间有一个会议。究竟是什么使得代理有理由推断：客户提起这个会议，是为了告知代理出行日期？

说话人似乎期待听话人作出某些推断；换句话
说，说话人传达的信息比说出的话语表面上呈现的更多。这类例子由 Grice（1975，1978）在其会话含义理论中提出。会话含义指一类特定的、有依据的推断。Grice 提出，听话人之所以能作出这些推断，是因为会话受一整套准则引导，这些准则是具有普遍性的经验法则，在会话话语的解释中起指导作用。其中一条准则是关联准则，它要求说话人努力做到与话题相关，

> `implicature`（会话含义）
>
> 释义：话语字面意义之外、听话人依据会话准则推导出来的那层言外之意。

> `relevance`（关联）
>
> 释义：要求说话人所说的话与当前话题及对方期待相契合的一条会话准则。

他们不会只是随意地说出言语行为。当客户提到 12 号有一个会议时，代理会这样推理：“提起这个会议必定有某种关联。

那会是什么呢？”代理知道，开会的先决条件之一（至少在网络会议出现之前）是人要身处会议举行地，因此这个会议也许正是出行的理由；而若果真如此，那么既然人们通常喜欢在会议前一天到达，代理就应当推断航班应订在 11 号。

人类对话的这些细微特征（话轮、言语行为、共同基础建立、对话结构、主动权以及会话含义）正是难以构建出能与人类进行自然对话的对话系统的原因之一。

这些挑战中的许多正是对话系统研究的活跃领域。

## 26.2 对话行为与语料库

> `dialogue act`（对话行为）
>
> 释义：用标签表示一句话在对话中所起的互动功能，如提问、确认或建议。

句子的互动功能。

对话行为可用于分析人际对话或人与 LLM 的
对话。参与者的性质以及对话的类型（基于任务或不基于任务）都会影响对话行为标记集的制定。

DAMSL 的后向功能关注一个话语与另一位说话人此前话语之间的关系。这类功能包括接受和拒绝提议（因为 DAMSL 关注的是面向任务的对话），以及共同基础建立和修复行为：

| 后向功能 |  |  |
| --- | --- | --- |
| AGREEMENT |  | 说话人对先前提议的回应 |
|  | ACCEPT | 接受该提议 |
|  | ACCEPT-PART | 接受提议的某一部分 |
|  | MAYBE | 既不接受也不拒绝该提议 |
|  | REJECT-PART | 拒绝提议的某一部分 |
|  | REJECT | 拒绝该提议 |
|  | HOLD | 推迟回应，通常借助子对话 |
| ANSWER |  | 回答一个问题 |
| UNDERSTANDING |  | 说话人是否理解了此前的话语 |
|  | SIGNAL-NON-UNDER. | 说话人没有理解 |
|  | SIGNAL-UNDER. | 说话人确实理解了 |
|  | ACK | 通过继续信号或评价来体现 |
|  | REPEAT-REPHRASE | 通过重复或重新表述来体现 |
|  | COMPLETION | 通过协作式补全来体现 |
