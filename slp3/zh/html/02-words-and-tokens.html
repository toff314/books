2.4.2 BPE 编码器

一旦我们学好了词表，就用 BPE 编码器对测试句子进行分词。编码器只是把从训练数据中学到的合并操作作用到测试数据上。它按照我们学到这些合并的顺序来执行（也就是贪心方式，即从训练数据中出现频率最高的开始）。测试数据中的频率并不起作用，起作用的只是训练数据中的频率。因此，我们先把测试句子中的每个词切分成字符。然后应用第一条规则：把测试语料中每一处 n e 都替换为 ne；接着应用第二条规则：把测试语料中每一处 ne w 都替换为 new，依此类推。到最后，许多合并当然只是重建了训练集中的词。但这些合并也带来了对语素的认知，例如 re- 前缀（它可能出现在诸如 revisit 或 rearrange 这类也许未见过的组合中），或者不带词首空格的语素 new（因而位于词内部），它可能出现在句首，也可能出现在训练中未见过的词里，如 anew。

当然，在实际场景中，BPE 通过数万次合并运行在一个非常

庞大的输入语料库上，以得到 50,000、100,000 甚至 200,000 个 token 的词汇表规模。结果是，大多数词都可以表示为单个 token，只有更罕见的词（以及未知词）需要用多个 token 来表示。

至少对英语是如此。对多语言系统而言，token 可能由英语占据主导，留给其他语言的 token 更少，我们将在下文讨论这一点。

2.10 小结

本章介绍了语言处理中词元与词元化的基本概念。我们讨论了词、语素和字符这几个语言层级，介绍了 Unicode 码点和 UTF-8 编码，介绍了用于词元化的 BPE 算法，并介绍了正则表达式以及用于比较字符串的最小编辑距离算法。以下是我们就这些内容所涉及要点的总结：

  • 词和语素是有用的表示单位，但很难给出形式化的定义。
  • Unicode 是一个用于表示世界上各种语言所用众多书写系统中字符的系统。
  • 每个字符在内部都用一个称为码点（code point）的唯一编号来表示，并且可以通过 UTF-8 之类的编码方式编码到文件中，UTF-8 是一种可变长度编码。
  • 字节对编码（Byte-Pair Encoding，BPE）是以数据驱动方式归纳出词元的标准方法。它是大多数大语言模型的第一步。
  • BPE 词元的粒度通常大致相当于词或语素，尽管它们也可以小到单个字符。

历史注记 65

  • 正则表达式语言是一种强大的模式匹配工具。
  • 正则表达式的基本操作包括符号的析取（[,]、|）、计数器（*、+ 和 {n,m}）、锚点（ˆ、$）、捕获组（(、)）以及替换。
  • 两个字符串之间的最小编辑距离是把其中一个编辑成另一个所需的最少操作次数。最小编辑距离可以用动态规划计算，计算过程还会给出两个字符串的一种对齐。
